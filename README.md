Solara Bay is a complete open-world crime game in the spirit of GTA 6: a sun-soaked coastal city to explore on foot and by car, with traffic and pedestrians, cars to steal, a wanted level with police who chase and bust you, a six-mission story, combat, and a HUD with a live minimap. It runs offline in a desktop browser from static files, keyboard + mouse.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
